Jean Didier veut une interface Jupply qui se comprend seule, « comme WhatsApp » : pas de phrases d'aide ni de notes explicatives à l'écran (ex. « Rien de coché = tous », « Les sorties précédentes sont dans l'Historique », « Clic sur une ligne pour... »). Il les fait retirer à chaque fois.

**Why:** les utilisateurs doivent savoir quoi faire sans qu'on leur explique ; un texte d'explication est le signe d'un écran pas assez évident.

**How to apply:** rendre l'usage évident par la structure (libellés courts, icônes parlantes, comportements attendus : clic sur la ligne = ouvrir, rouge = à corriger) ; garder les explications pour les bulles au survol (`title`) et les messages d'erreur ; écrans de travail simples, le filtrage avancé et les exports vont dans l'Historique. Termes simples (« Montant » plutôt que « Valeur »). Voir aussi [[confirmations-actions-sensibles]].
